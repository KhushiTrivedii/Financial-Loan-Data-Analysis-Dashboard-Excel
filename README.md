Financial Loan Data Analysis Dashboard | Excel
An interactive Microsoft Excel dashboard designed to explore loan applications, funded amounts, repayment performance, loan status, borrower characteristics, and loan distribution across different categories. The project uses PivotTables, charts, and slicers to turn raw loan data into a visual summary for exploratory financial analysis.
📌 Project Overview
Short Description / Purpose
The Financial Loan Data Analysis Dashboard was created as a practice project while learning how to build interactive dashboards in Microsoft Excel. It explores loan portfolio information, including loan status, loan purpose, borrower employment and income characteristics, credit grades, and repayment-related measures.

The workbook includes dashboard sheets, a design sheet, and a data sheet. It demonstrates practical skills in spreadsheet-based analysis, KPI reporting, data summarization, and interactive dashboard design.
🛠️ Tech Stack
The project uses the following tools and features:
- 📗 Microsoft Excel – Built the dashboard and organized the workbook.
- 📊 PivotTables & PivotCharts – Summarized loan records and compared loan metrics across categories.
- 🎛️ Slicers / Interactive Filters – Enabled users to filter dashboard views by supported categories.
- 🧮 Excel Calculations & Aggregations – Supported KPI summaries and category-level analysis.
- 📈 Data Visualization & Reporting – Presented loan portfolio patterns through charts and dashboard visuals.
📂 Data Source
Dataset: Financial Loan Data (Excel workbook)

The workbook contains approximately 38,576 data records in the Data sheet, along with dashboard and design sheets. Fields in the dataset include:
- Loan Information: Loan amount, installment, loan term, loan status, and issue date.
- Borrower Information: Employment length, annual income, home ownership, and debt-to-income ratio (DTI).
- Credit Information: Loan grade, sub-grade, interest rate, and verification status.
- Additional Details: Loan purpose, state, employment title, payment dates, total accounts, and total payment.
The data is included in the workbook for analysis. The reported row count refers to the records in the provided file and may differ if the data is updated or filtered.
🎯 Features & Highlights
1. Business Problem
Loan portfolios contain many records and multiple attributes related to borrowers, loan terms, credit grades, and repayment status. Reviewing these records individually makes it difficult to understand portfolio composition, compare loan categories, and monitor repayment-related patterns.

This dashboard consolidates key loan metrics and category-level comparisons into an interactive Excel report, helping users explore the data more efficiently.
2. Goal of the Dashboard
The primary objectives of this project are to:
- Summarize key loan portfolio metrics in one place.
- Explore the distribution of loans by status, purpose, term, and credit grade.
- Compare loan amounts and repayment-related measures across categories.
- Examine borrower characteristics such as employment length, annual income, home ownership, and DTI.
- Use interactive filters to explore selected segments of the dataset.
- Practice creating a structured, readable dashboard in Excel.
3. Walkthrough of the Workbook
The workbook includes the following sheets:
- Design Sheet: A supporting sheet used for dashboard layout or chart-related data.
- Overview Dashboard: A dashboard view for reviewing high-level loan portfolio metrics and visual summaries.
- Dashboard: An additional dashboard sheet containing loan analysis visuals.
- Data: The underlying loan dataset used for analysis.
The exact metrics and visuals shown may depend on the current workbook state and Excel version.
4. Business Impact & Potential Insights
The dashboard can be used to explore questions such as:
- Loan Status: How are loans distributed across statuses such as fully paid, current, or charged off?
- Loan Purpose: Which purposes account for a larger share of loan applications or loan amounts?
- Credit Grades: How do loan amounts and interest rates vary across credit grades and sub-grades?
- Loan Terms: How does the portfolio split between different loan terms?
- Borrower Profile: How do employment length, home ownership, and annual income vary across loan records?
- Repayment Patterns: How do total payments and loan status vary across categories?
These are analysis questions the dashboard supports; specific findings should be reported only after checking the values and visuals in the workbook.

Potential Business Applications
- Portfolio Monitoring: Review loan distribution and status at a high level.
- Credit Analysis: Compare portfolio segments by grade, sub-grade, interest rate, and DTI.
- Borrower Segmentation: Explore patterns across employment, income, home ownership, and loan purpose.
- Reporting: Use PivotTables, charts, and slicers to summarize records for further investigation.
Note: This is an educational practice project based on a tutorial workflow. The dashboard provides descriptive analysis and does not establish causation, predict credit risk, or constitute financial advice.
